# Shyam Mohan Singh - Professional Portfolio

A modern, premium-looking personal portfolio website built with **HTML, CSS, and Vanilla JavaScript**. Fully compatible with GitHub Pages and requires no build process or backend server.

## 🌟 Features

### Design & UX
- **Modern & Premium UI** - Contemporary design with gradient accents and smooth animations
- **Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- **Fast & Performant** - Pure HTML/CSS/JS with no external dependencies
- **Accessible** - Semantic HTML and keyboard navigation support
- **Dark-friendly** - Built with clear contrast and readability

### Functionality
- **Smooth Navigation** - Smooth scroll and active section highlighting
- **Mobile-Friendly Menu** - Hamburger menu for small screens
- **Contact Form** - Functional contact form with validation
- **Scroll Animations** - Fade-in and slide animations as you scroll
- **Button Ripple Effects** - Interactive ripple effect on clicks
- **Social Links** - Quick links to GitHub and LinkedIn profiles

### Content Sections
1. **Hero Section** - Eye-catching introduction with CTA buttons
2. **About** - Professional background and key statistics
3. **Technical Skills** - Organized by Backend, Frontend, Cloud, DevOps, Tools
4. **Featured Projects** - Highlighted flagship project with details
5. **Other Projects** - Grid layout of additional projects
6. **Professional Experience** - Timeline of work history
7. **Education** - Academic background
8. **Contact** - Contact form and social links

## 🚀 Getting Started

### Local Development
1. Clone or download this repository
2. Open `index.html` in your web browser
3. Make changes and refresh to see updates

### Deploy to GitHub Pages
1. Push the files to your GitHub repository
2. Go to Settings → Pages
3. Set Source to "main" branch (or your default branch)
4. Your site will be live at `https://username.github.io/Portfolio`

## 🛠️ Customization

### Update Personal Information
Edit these sections in `index.html`:
- Hero section with your name and title
- About section with your bio
- Skills section with your technical skills
- Projects section with your work
- Experience section with your job history
- Contact form with your email

### Customize Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #ec4899;
    /* ... other colors ... */
}
```

### Add Your Projects
Each project is a `.project-card`. Update:
- Project title
- Project description
- Technologies used
- Project links (GitHub, Live URL)

### Modify Styles
- All styles are in `styles.css`
- Variables are defined at the top for easy customization
- Responsive breakpoints are at the bottom
